
# ☕ Campus Café Website

A responsive web application built using **HTML, CSS, and JavaScript**.  
The project simulates a digital campus café system where users can browse menu items and interact with a simple ordering interface.

This project is designed with scalability in mind, allowing future integration of backend technologies for authentication, database management, and full order processing.

- 🧾 Clean and organized café menu display
- 🔍 Easy navigation through sections
- 🛒 Basic cart/order simulation
- 📱 Fully responsive design for mobile and desktop
- 🎨 Modern and user-friendly interface
- ⚡ Lightweight and fast performance

# Campus Café

A responsive campus food ordering web app with menu browsing, cart management, checkout flow, and authentication screens.

## Description

Campus Café is a static front-end prototype designed for a university food ordering experience. It includes a home page, menu browsing, shopping cart, checkout form, and login/register pages. The current implementation uses `localStorage` for cart persistence and mock authentication.

## Features

- Responsive landing page and menu browsing
- Add items to cart and view cart summary
- Checkout form for order details
- Login form with basic client-side validation
- LocalStorage persistence for cart and user session
- Smooth scroll navigation and animated sections

## Current scope

This repository currently contains the front-end experience only. Order checkout and user authentication are simulated in the browser.

## Backend integration (future)

When moving to a production-ready system, the order flow should be backed by a server-side API that handles:

- Menu data fetching from a database
- User authentication and session management
- Order creation, validation, and persistence
- Payment processing or payment method selection
- Order status tracking and delivery workflow

## Getting started

1. Open the project folder in your editor.
2. Open `index.html` in a browser.
3. Use the app to browse the menu, add items to the cart, and proceed to checkout.

## File structure

- `index.html` — home page and featured menu
- `menu.html` — menu browsing page
- `login.html` — login page
- `register.html` — account registration page
- `checkout.html` — checkout/order form page
- `script.js` — front-end interactions, cart management, and form handling
- `styles.css` — shared site styling

## Notes

This project is ideal as a front-end prototype for Campus Café. The next step is to connect the UI with a backend service for real order processing and secure authentication.
